# 밸런스 게임 웹앱 (성향 분석 버전)

단일 HTML 파일로 동작하는 가볍고 재미있는 밸런스 게임입니다. 사용자의 선택을 바탕으로 숨겨진 성향을 분석해 주는 기능이 추가되었습니다.

## 주요 기능
- **밸런스 게임**: 두 가지 선택지 중 하나를 고르는 짜릿한 고민!
- **성향 분석**: 선택한 답변들을 종합하여 4가지 성향(모험가, 안정추구, 현실주의, 이상주의) 중 하나를 결과로 보여줍니다.
- **랜덤 출제**: 게임을 할 때마다 질문 순서가 무작위로 바뀝니다.
- **질문 추가 기능**: 게임 화면 아래에서 나만의 질문과 성향을 직접 추가할 수 있습니다.
- **결과 모아보기**: 게임이 끝난 후, 내가 어떤 선택을 했는지 한눈에 확인할 수 있습니다.
- **반응형 디자인**: PC뿐만 아니라 스마트폰 화면에서도 깔끔하게 보입니다.

## 실행 방법
따로 설치할 프로그램이나 서버가 필요 없습니다. 
다운로드하신 `index.html` 파일을 더블클릭하여 인터넷 브라우저(크롬, 엣지, 사파리 등)로 열기만 하면 바로 게임이 시작됩니다.

## 질문 및 성향 수정 방법
메모장 등 텍스트 편집기로 `index.html` 파일을 엽니다.
코드 중간에 있는 `[1. 성향 결과 코멘트 수정하는 곳]`과 `[2. 질문 수정하는 곳]` 부분을 찾아, 괄호 안의 글자들을 원하는 대로 바꾸고 저장하면 됩니다.
