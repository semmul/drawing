# 🌱 에코링고 (EcoLingo) 웹앱

나의 관심 분야(환경, 지속가능발전, AI 등)를 바탕으로 실무 영어를 학습하고, 에빙하우스의 망각 곡선에 맞춰 간격 반복 복습(Spaced Repetition)을 할 수 있는 인터랙티브 웹앱입니다.

---

## 🛠️ 주요 기능

1. **관심 분야 다중 선택 및 융합 학습**
   - 환경, 공정무역, AI 등 관심 분야를 선택하면 해당 분야의 실무 용어와 뉴스를 보여줍니다.
   - 2개 이상의 분야가 결합된(예: 지속가능발전 + AI) 실전 융합 문장을 한국어 실무 버전과 원어민 대사 버전으로 동시에 학습할 수 있습니다.

2. **뉴스 문맥 하이라이트**
   - 단어가 실제 해외 뉴스나 실무에서 어떻게 쓰이는지 문맥 속에서 굵은 글씨로 강조하여 제공합니다.

3. **에빙하우스 복습 대시보드**
   - 학습 완료 버튼을 누르면 1일, 3일, 7일, 14일, 30일 주기로 복습할 수 있도록 로컬 스토리지에 자동 스케줄링됩니다.
   - '복습 대시보드' 탭에서 오늘 복습해야 할 분량만 깔끔하게 모아볼 수 있습니다.

4. **나만의 생각 메모**
   - 각 단어나 문장 하단에 나만의 예문이나 아이디어를 기록할 수 있습니다. (입력 후 바깥을 클릭하면 자동 저장됩니다.)

5. **상황 및 맥락 검색기**
   - 영어 단어가 떠오르지 않을 때, "친환경인 척" 또는 "정당한 대가" 같은 우리말 맥락을 검색하면 그에 맞는 실무 영어(Greenwashing, Fair Price 등)를 찾아줍니다.

---

## 🚀 사용 방법 및 배포 가이드 (Windows 기준)

### 1단계: 파일 저장하기
1. 컴퓨터의 **내 컴퓨터 > 문서 > 바이브코딩** 경로에 새 폴더를 만듭니다. (예: `ecolingo`)
2. 다운로드한 **`index.html`** 파일과 **`readme.md`** 파일을 해당 폴더 안에 넣습니다.

### 2단계: 깃허브(GitHub)에 업로드하기
1. 깃허브(GitHub) 사이트에 접속하여 우측 상단의 **+** 버튼을 누르고 **New repository**를 선택합니다.
2. 저장소 이름(Repository name)을 입력한 뒤, **Create repository**를 누릅니다.
3. 화면에 나오는 안내 중 **"uploading an existing file"**(기존 파일을 업로드하여 시작하세요) 문구를 클릭합니다.
4. 준비된 파일 2개(`index.html`, `readme.md`)를 업로드 영역에 넣고, 하단의 **Commit changes** 버튼을 눌러 저장합니다.

### 3단계: 버셀(Vercel)에서 프로젝트 연결하기
1. 버셀(Vercel) 사이트에 접속하여 **Add New**(또는 Create New)를 누르고 **Project**를 선택합니다.
2. 방금 만든 깃허브 저장소가 목록에 나오면 **Import**를 누릅니다.
3. 프로젝트 설정 화면 아래에 있는 **Deploy** 버튼을 누릅니다.

### 4단계: 배포 완료 및 URL 복사하기
1. 잠시 후 **"Congratulations!"** 문구와 함께 축하 화면과 실행 창이 뜹니다.
2. 화면을 클릭하여 HTML 페이지가 잘 뜨는지 확인하고, 브라우저의 **URL 주소창에서 주소를 복사**합니다.

### 5단계: 북마크 및 실전 사용하기
- 복사한 URL을 브라우저 즐겨찾기(북마크)에 등록해 두고, 매일 접속하여 '오늘의 복습'과 '새로운 문장 학습'을 진행해 보세요! 데이터는 브라우저에 안전하게 자동 저장됩니다.
